## 5.6 Analysis Models: User Stories (draft v1, 26 Nov 2026)

### 5.6.8 User stories

**Owner.** Zeynep (Business Analyst). Draft v1, 26 Nov 2026.

**Basis.** Each story covers one or more functional requirements in 5.4 (FR-01 to FR-55), one use case (UC-01 to UC-10, numbering as in the traceability table of 5.6.3) and the business rules R1–R9 of the project card. Actor names are the project card names. Priorities follow the MoSCoW priority of the related FRs in 5.4.

**Format.** *As a <actor>, I want <goal> so that <benefit>.* Each story has acceptance criteria in Given/When/Then form. The criteria use the exact limits of the rules (3 hours, 2 and 5 active reservations, 10 and 15 minutes, 3 no-shows in 30 days, 7 days), so they can be turned directly into test cases in 5.12.

#### 5.6.8.2 Stories and acceptance criteria

##### US-01 Register an account
*As a Student or Academic Staff member, I want to register with my name, e-mail and password so that I can book campus resources myself.*

- **AC1** Given I am not registered, when I enter full name, e-mail, password and choose the role `STUDENT` or `ACADEMIC_STAFF`, then my account is created and I can log in.
- **AC2** Given the registration form, when I look at the role options, then `RESOURCE_ADMIN` is not offered.
- **AC3** Given an account already exists with my e-mail, when I try to register with the same e-mail, then the registration is refused with a message that the e-mail is already registered.

##### US-02 Log in and see only what my role allows
*As a Campus User or Resource Admin, I want to log in and see only the functions of my role so that I am not confused by functions I cannot use and others cannot use mine.*

- **AC1** Given a registered account, when I enter the correct e-mail and password, then I am logged in.
- **AC2** Given a registered account, when I enter a wrong password, then I am not logged in and I see an error message.
- **AC3** Given I am logged in as `STUDENT` or `ACADEMIC_STAFF`, when I try to open an admin function, then access is refused.
- **AC4** Given I am logged in as `RESOURCE_ADMIN`, when I try to create a reservation or check in, then the action is refused (D3).
- **AC5** Given I am logged in, when I log out, then I must log in again to use protected functions.

##### US-03 Search and filter resources
*As a Student, I want to search resources by name or location and filter them by type and capacity so that I find a suitable place quickly.*

- **AC1** Given active resources exist, when I open the resource list, then I see each resource's name, type, location, capacity and description.
- **AC2** Given the list, when I type part of a name or location, then only matching resources are shown.
- **AC3** Given the list, when I choose type `LAB` and minimum capacity 20, then only labs with capacity 20 or more are shown.
- **AC4** Given a resource is deactivated, when I search, then it is not shown as bookable.

##### US-04 See the availability calendar of a resource
*As a Student, I want to see the free and booked time slots of a resource for a day so that I can choose a time that is actually free.*

- **AC1** Given a resource and a date, when I open its calendar, then I see the booked and the free time slots of that day.
- **AC2** Given a reservation in state `PENDING_APPROVAL`, `CONFIRMED` or `CHECKED_IN` covers 14:00–16:00, when I open the calendar, then 14:00–16:00 is shown as booked (D2).
- **AC3** Given a reservation for 14:00–16:00 is `CANCELLED`, `REJECTED` or `NO_SHOW`, when I open the calendar, then 14:00–16:00 is shown as free.

##### US-05 Reserve a room or a lab
*As a Student, I want to reserve a room or a lab for a time slot so that the place is kept for me.*

- **AC1** Given I have no penalty and fewer than 2 active reservations, and Lab A is free from 10:00 to 13:00 tomorrow, when I reserve Lab A for 10:00–13:00 (exactly 3 hours), then the reservation is created in state `CONFIRMED` (R1, R5).
- **AC2** Given the same situation, when I try to reserve Lab A for 10:00–13:01, then the reservation is refused and the message says the maximum length is 3 hours (R1).
- **AC3** Given Lab A is already reserved 11:00–12:00, when I try to reserve Lab A for 10:00–12:00, then the reservation is refused and the message says the time overlaps another reservation (R3).
- **AC4** Given the current time is 15:00, when I try to reserve a slot that starts at 14:00 today, or a slot whose end is not after its start, then the reservation is refused.
- **AC5** Given my reservation was created, when I open my notifications, then I see a notification that the reservation is confirmed.

##### US-06 Be stopped by my active-reservation limit
*As a Student or Academic Staff member, I want the system to tell me when I reach my active-reservation limit so that I understand why I cannot book more, and resources are shared fairly.*

- **AC1** Given I am a `STUDENT` with 2 active reservations (future start, state `PENDING_APPROVAL` or `CONFIRMED`), when I try to make a third, then it is refused and the message names the limit of 2 (R2, D1).
- **AC2** Given I am an `ACADEMIC_STAFF` member with 4 active reservations, when I make a fifth, then it is accepted; when I then try a sixth, it is refused with the limit of 5 (R2).
- **AC3** Given I am a `STUDENT` with 2 active reservations, when I cancel one of them, then I can make a new reservation (D1).

##### US-07 Be told when a penalty blocks me
*As a Student, I want to see that I have a penalty and when it ends so that I know when I can book again.*

- **AC1** Given I have a penalty that ends on 10 Dec at 09:00, when I try to make a reservation on 5 Dec, then it is refused and the message shows the end of the penalty (R4).
- **AC2** Given I have a penalty, when I open my reservations, then I see the end date of the penalty.
- **AC3** Given my penalty ended, when I make a reservation that meets R1–R3, then it is accepted.

##### US-08 Request equipment
*As an Academic Staff member, I want to request a piece of equipment for a time slot so that I can use it for my class or research after the admin approves it.*

- **AC1** Given a free `EQUIPMENT` item and no rule violation, when I reserve it, then the reservation is created in state `PENDING_APPROVAL`, not `CONFIRMED` (R5).
- **AC2** Given my equipment reservation is pending, when I open my notifications, then I see that it is waiting for approval.
- **AC3** Given my equipment reservation is pending, when another user tries to reserve the same item for an overlapping time, then that user is refused (D2).

##### US-09 See my reservations
*As a Student, I want to see all my reservations and their states so that I know what I have booked and what happened to each booking.*

- **AC1** Given I have reservations, when I open "My reservations", then I see for each one the resource, start, end, purpose and state.
- **AC2** Given the list, when I filter by state `CONFIRMED`, then only confirmed reservations are shown.
- **AC3** Given an equipment reservation was rejected, when I open it in the list, then I see the rejection reason.

##### US-10 Cancel a reservation
*As a Student, I want to cancel a reservation I no longer need so that someone else can use the place.*

- **AC1** Given my reservation is `CONFIRMED` and starts at 14:00, when I cancel it at 13:59, then its state becomes `CANCELLED` and the slot is free in the calendar (R6, D2).
- **AC2** Given the same reservation, when I try to cancel it at 14:00 or later, then the cancellation is refused (R6).
- **AC3** Given I cancelled a reservation, when I count my active reservations, then the cancelled one is not counted (D1).
- **AC4** Given my equipment reservation is `PENDING_APPROVAL`, when I cancel it before its start, then its state becomes `CANCELLED`.

##### US-11 Check in by scanning the QR code
*As a Student, I want to check in by scanning the QR code on the door with my phone so that the system knows I came and does not release my place.*

- **AC1** Given I have a `CONFIRMED` reservation for Lab A that starts at 10:00, when I scan Lab A's QR code at 09:50 (10 minutes before), then my reservation becomes `CHECKED_IN` and the time and method "QR scan" are recorded (R7).
- **AC2** Given the same reservation, when I scan at 10:15 (15 minutes after the start), then the check-in is accepted (R7).
- **AC3** Given the same reservation, when I scan at 09:49 or at 10:16, then the check-in is refused and the message says the check-in window is closed or not yet open (R7).
- **AC4** Given my reservation is for Lab A, when I scan the QR code of Lab B, then the check-in is refused and the message says I have no reservation for this resource.
- **AC5** Given I have already checked in, when I scan again, then no second check-in is recorded.

##### US-12 Check in with the 6-digit code
*As a Student, I want to type the 6-digit code under the QR code when my camera does not work so that I can still check in.*

- **AC1** Given the camera cannot be opened on my phone, when I open the check-in screen, then I can enter the 6-digit code on the same screen.
- **AC2** Given a `CONFIRMED` reservation inside the R7 window, when I enter the correct 6-digit code of the resource, then my reservation becomes `CHECKED_IN` and the method "manual code" is recorded.
- **AC3** Given the same reservation, when I enter a wrong code, then the check-in is refused.

##### US-13 Release a no-show reservation
*As the System Scheduler, I want to mark reservations without a check-in as no-shows 15 minutes after the start so that the resource is released for other users.*

- **AC1** Given a `CONFIRMED` reservation started at 10:00 and has no check-in, when the scheduler runs after 10:15, then the reservation becomes `NO_SHOW` (R8).
- **AC2** Given the reservation became `NO_SHOW`, when another user opens the calendar, then the rest of the slot is shown as free (R8).
- **AC3** Given a reservation was checked in at 10:05, when the scheduler runs after 10:15, then the reservation is not changed.
- **AC4** Given a reservation became `NO_SHOW`, when the user opens the notifications, then a "no-show recorded" notification is shown.

##### US-14 Apply a penalty after repeated no-shows
*As the System Scheduler, I want to give a 7-day booking ban to users with 3 no-shows in 30 days so that repeated no-shows have a consequence and places are not wasted.*

- **AC1** Given a user has 2 `NO_SHOW` reservations in the last 30 days, when a third reservation becomes `NO_SHOW`, then a Penalty of 7 days is created for the user (R9).
- **AC2** Given a user has 3 `NO_SHOW` reservations but one of them is older than 30 days, when the scheduler runs, then no penalty is created (R9).
- **AC3** Given a penalty was created, when the user opens the notifications, then a "penalty applied" notification with the end date is shown.

Note: whether the no-shows that already caused a penalty are counted again for the next penalty is decided under HANDOFFS H09. AC1 and AC2 hold in both cases.

##### US-15 Complete and auto-reject reservations on time
*As the System Scheduler, I want to close reservations that have ended and reject equipment requests nobody decided on so that the states always show what really happened.*

- **AC1** Given a `CHECKED_IN` reservation ends at 12:00, when the scheduler runs after 12:00, then the reservation becomes `COMPLETED`.
- **AC2** Given an `EQUIPMENT` reservation is still `PENDING_APPROVAL` at its start time, when the scheduler runs, then it becomes `REJECTED` with a system reason, the slot is free and the user is notified (D4).

##### US-16 Approve or reject equipment reservations
*As a Resource Admin, I want to see pending equipment reservations and approve or reject them so that equipment is lent only for valid requests.*

- **AC1** Given pending `EQUIPMENT` reservations exist, when I open the approvals screen, then I see each one with user, resource, time and purpose.
- **AC2** Given a pending reservation, when I approve it, then it becomes `CONFIRMED`, my name and the time of the decision are recorded, and the user is notified.
- **AC3** Given a pending reservation, when I reject it with the reason "Device under repair", then it becomes `REJECTED`, the reason is stored, the slot is free and the user is notified.
- **AC4** Given a reservation was rejected, when the user counts active reservations, then the rejected one is not counted (D1).

##### US-17 Manage resources
*As a Resource Admin, I want to add, edit and deactivate resources so that the list users see is correct.*

- **AC1** Given I am a Resource Admin, when I create a resource with name, type, location, capacity and description, then it is saved and the system generates its QR code and 6-digit code; I do not type them.
- **AC2** Given two resources, when I compare their QR codes and 6-digit codes, then no two resources have the same code.
- **AC3** Given a resource, when I edit its capacity, then users see the new capacity.
- **AC4** Given a resource, when I deactivate it, then it is not deleted, and users no longer see it as bookable.

##### US-18 View occupancy, no-show and penalty reports
*As a Resource Admin, I want to see how resources are used, who did not show up and who has a penalty so that I can plan resources and follow up misuse.*

- **AC1** Given reservations exist in a chosen period, when I open the usage report for that period, then I see per resource the number of reservations, the booked hours and the occupancy rate.
- **AC2** Given no-shows exist in the period, when I open the no-show report, then I see per user the number of no-shows and the date of the last one.
- **AC3** Given penalties exist, when I open the penalties list, then I see the user, reason, start and end of each penalty.

##### US-19 Read my in-app notifications
*As a Student, I want to see my notifications in the application so that I know about approvals, rejections, no-shows and penalties without checking every reservation.*

- **AC1** Given I have notifications, when I open the notifications list, then I see them newest first with a read/unread mark.
- **AC2** Given an unread notification, when I mark it as read, then it is shown as read.
- **AC3** Given one of these events happens to my reservation — confirmed, pending, approved, rejected, cancelled, no-show recorded, penalty applied — when I open the list, then a notification for that event is shown.
