## 2. Review checklist (answer for each document found)

1. Which data fields does the document collect (name, student ID, date, time, purpose, number of people, etc.)?
2. Who fills it in, and who approves it?
3. Is there a time limit per booking, or a limit per person?
4. How is a booking cancelled? Is there a deadline for cancellation?
5. Is there any rule for not showing up or for late return of equipment?
6. How are conflicts (two requests for the same slot) handled?
7. Is usage recorded or reported anywhere (utilisation, no-shows)?
8. How long is the data kept, and who can see it?
9. What problems does the document show (missing fields, manual steps, duplicated work)?
